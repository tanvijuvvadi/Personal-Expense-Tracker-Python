# 💰 Personal Expense Tracker with Data Visualization

## 📌 Project Overview

This project is a Python-based Personal Expense Tracker built using **Google Colab**. It analyzes daily expenses and generates meaningful insights through data visualization.

The goal is to understand spending patterns, identify trends, and improve financial decision-making.

## 🎯 Problem Statement

Tracking expenses manually is difficult and often leads to overspending.
This project helps organize expense data and provides clear insights using charts and analysis.


## 🚀 Features

* 📊 Category-wise spending analysis
* 📈 Monthly spending trend visualization
* 🥧 Payment method distribution (Donut Chart)
* 📉 Daily spending analysis (Highest & Lowest day detection)
* 📄 Automated summary report generation
* 🎨 Professional data visualizations


## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
